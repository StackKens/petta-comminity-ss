# Modern Secondary School Website — Master Build Prompt

Design and build a **premium, modern, professional secondary school website** for a Ugandan secondary school offering both **O-Level and A-Level education**.

The website should feel like a serious, established educational institution — trustworthy to parents, inspiring to students, professional to teachers, and impressive to visitors.

Do **not** make it look like a generic school template. The design should feel custom-built, modern, elegant, highly polished, and comparable to the quality of a premium international school website while still feeling authentic to a Ugandan school.

## Core Design Direction

Use a visual identity that communicates:

* Academic excellence
* Discipline
* Character
* Leadership
* Growth
* Community
* Trust
* Excellence
* Modern education

### Visual Style

Use:

* Clean modern layouts
* Generous whitespace
* Strong typography
* Large high-quality photography
* Elegant cards
* Subtle borders
* Soft shadows
* Smooth hover states
* Tasteful animations
* Rounded corners, but avoid excessive "playful" UI
* Strong visual hierarchy
* Responsive layouts
* Professional navigation
* Excellent mobile experience

Use the school's existing brand colors if provided. If no colors are provided, create a refined palette based around:

* Deep navy / royal blue
* White
* Subtle gold or warm accent
* Light neutral backgrounds

Do not use excessive gradients, neon colors, cartoon illustrations, or overly flashy animations.

The overall feeling should be:

**Prestigious + Academic + Modern + Warm + Trustworthy**

# TECHNICAL ARCHITECTURE

Build the website using a modern component-based architecture.

Keep components reusable.

Suggested structure:

```text
src/
├── components/
│   ├── Navbar
│   ├── Footer
│   ├── Hero
│   ├── SectionHeader
│   ├── Button
│   ├── StatCard
│   ├── FeatureCard
│   ├── NewsCard
│   ├── TestimonialCard
│   ├── FacilityCard
│   └── ...
│
├── pages/
│   ├── Home
│   ├── About
│   ├── Academics
│   ├── Admissions
│   ├── StudentLife
│   ├── Facilities
│   ├── News
│   ├── Gallery
│   └── Contact
│
├── data/
│   └── schoolData
│
├── assets/
│   ├── images
│   └── icons
│
└── ...
```

Do not duplicate UI unnecessarily.

Create reusable components and data-driven sections.

# CONTENT RULE

Very important:

**Do not fabricate school-specific facts.**

If information such as:

* School name
* Location
* Fees
* Subject combinations
* Boarding availability
* Number of students
* Academic results
* History
* Staff names
* Phone numbers
* Email addresses

is unknown, use clearly marked placeholders.

Example:

`[School Name]`

`[School Address]`

`[Phone Number]`

`[School Email]`

`[Insert A-Level Subject Combinations]`

Never invent achievements, examination results, partnerships or statistics.

---

# FINAL DESIGN GOAL

The finished website should feel like a school that a parent would trust with their child's education.

When someone lands on the homepage, the reaction should be:

**"This is a serious, modern and well-organized school."**

Prioritize:

**Trust → Academic Excellence → Character → Student Development → Admissions**

Do not make it feel like a generic template.

Build the experience as if this were a real premium secondary school preparing students for both **O-Level and A-Level**, with room to evolve into a larger digital school platform in the future.
